# CafeInsight

Data preprocessing and exploratory data analysis project for cafe sales data using Python and data visualization techniques.

---

## Project Overview

CafeInsight is a data analytics project focused on cleaning, preprocessing, and analyzing cafe sales data to uncover meaningful business insights.

The project demonstrates the complete data preprocessing workflow, including handling missing values, detecting inconsistencies, cleaning datasets, and generating visual analytics for business understanding.

---

## Dataset

### Original Dataset
- `dirty_cafe_sales.csv`

Contains raw cafe sales data with potential:
- Missing values
- Duplicate records
- Inconsistent formatting
- Data quality issues

---

### Cleaned Dataset
- `cafe_sales_cleaned.csv`

Processed version of the dataset after data cleaning and preprocessing steps.

---

## Project Objectives

The project aims to:

- Clean and preprocess raw cafe sales data
- Handle missing and inconsistent values
- Prepare data for analysis
- Perform exploratory data analysis (EDA)
- Visualize important sales insights
- Demonstrate practical data preprocessing techniques

## How to Clone This Repository

### Option 1: Clone Using Git

Run the following command in your terminal:

```bash
git clone https://github.com/your-username/cafeinsight.git
```

Move into the project folder:

```bash
cd cafeinsight
```

---

### Option 2: Download ZIP File

1. Click the green **Code** button on GitHub
2. Select **Download ZIP**
3. Extract the ZIP file
4. Open the extracted project folder

---

## How to Run the Project

### 1. Install Required Libraries

```bash
pip install pandas numpy matplotlib seaborn notebook
```

---

### 2. Launch Jupyter Notebook

```bash
jupyter notebook
```

---

### 3. Open the Notebook

Open:

```bash
cafe_cleaning.ipynb
```

Run all notebook cells to reproduce the preprocessing workflow and visualizations.
